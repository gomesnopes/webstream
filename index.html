3. Tes HLS Mux

Cara membaca hasil:
• Jika MP4 berhasil tetapi HLS gagal, kemungkinan masalahnya pada sumber HLS atau akses playlist/segmen.
• Jika semua tes gagal dengan kode 4, coba buka halaman ini dari alamat HTTPS biasa, bukan preview file/attachment. Browser preview atau konteks file lokal dapat membatasi akses media.
• Jika video siap tetapi tidak otomatis berjalan, tekan tombol Play di kontrol video. Safari sering membatasi autoplay.
• Stream yang memerlukan login, cookie, header khusus, token kedaluwarsa, atau DRM tidak akan otomatis berfungsi di player sederhana.
